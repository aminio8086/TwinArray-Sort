### Added
- Header-only C++20 reference implementation of TwinArray Sort.
- Copy-returning and direct-output reconstruction APIs.
- Deterministic, randomised, exhaustive small-domain and exception tests.
- Reproducible C++ benchmark against `std::sort`.
- CMake build configuration and cross-platform CI.
- Algorithm and benchmarking documentation.
- Apache-2.0 licensing and machine-readable citation metadata.
